# Ankush Sinha — Portfolio

A personal portfolio built with Next.js, React, JavaScript, and Tailwind CSS.

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment variables

Copy `.env.example` to `.env.local` to override the contact API or Google
Analytics ID. The contact form defaults to the existing portfolio API.

## Deployment

The project uses Next.js's native production build and is ready to deploy to
Vercel with its default Next.js framework detection.
